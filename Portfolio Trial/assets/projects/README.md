Drop project photos/renders here (`.jpg`, `.png`, `.webp`).

Then in [`js/projects-data.js`](../../js/projects-data.js), set that project's `image` field to
the relative path, e.g.:

```js
image: "assets/projects/uav-wing.jpg"
```

Recommended: keep each file under ~500KB and roughly 1200px wide — GitHub Pages has no image
processing, so whatever you upload is served as-is.
